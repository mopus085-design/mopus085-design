# Привет! / Hi! 👋

Разработчик встраиваемых систем, Android-приложений и инструментов для работы с видео. Люблю компактный код, реверс-инжиниринг протоколов и устройства, которые работают без облака.

Embedded systems, Android apps and video tooling developer. I like compact code, protocol reverse engineering, and devices that work without any cloud.

## 🛠 Проекты / Projects

### 🔧 [FFmpeg Encoder Queue](https://github.com/mopus085-design/ffmpeg-encoder-queue)
Настольное приложение Windows (Electron) для пакетной обработки видео и аудио через FFmpeg: очередь задач, обрезка, кроп, микшер дорожек, скачивание через yt-dlp, аппаратное кодирование. Плюс Android-версия **FF Mobile**.
`Electron` `FFmpeg` `yt-dlp` `Android` `Java`

### 📻 [Radio Messenger](https://github.com/mopus085-design/radio-messenger)
Мессенджер поверх радио-канала: ESP32 (BLE, LittleFS) + Android-клиент весом **~46 КиБ** без единой сторонней зависимости. Ветка new-02 — автономное устройство на ESP32-S3 с USB-клавиатурой и дисплеем ST7567S.
`ESP32` `BLE` `Java` `WebView` `C++`

### 🔐 [Cryptogram](https://github.com/mopus085-design/cryptogram)
Android-форк Rattlegram — передача данных через аудио-канал с шифрованием, повторами пакетов и помехоустойчивостью. Прошивка ESP32: аудиомост Bluetooth I2S, автономная запись с рации на SD.
`Android` `Java` `ESP32` `Cryptography` `DSP`

### 🎥 DJI Pocket 3 — прямое управление
Реверс-инжиниринг протокола DJI Osmo Pocket 3: управление подвесом с ПК через BLE + Wi-Fi (TCP/UDP, DUML-телеметрия). Приложение на Python/Tkinter/Bleak.
`Python` `BLE` `Reverse Engineering` `DUML`

### 🎞 SliderCam (в разработке)
Компактный Android-пульт для моторизованного слайдера камеры по BLE. Цель — APK до 150 КиБ: системный WebView, ноль сторонних зависимостей.
`Android` `BLE` `Embedded`
